# Neural Stage — downloads

Free downloads of **Neural Stage**, a live guitar rig host built around NAM amp models, by ATIJ STUDIO.

**Get it from the website:** <https://atij666studio.github.io/atijstudio/plugins/neural-stage/>,
or pick a file from the [latest release](../../releases/latest).

This repository only holds the installers. Neural Stage is freeware: free to use, no account or sign-up.

Built on Steven Atkinson's open-source [Neural Amp Modeler](https://github.com/sdatkinson/neural-amp-modeler).
